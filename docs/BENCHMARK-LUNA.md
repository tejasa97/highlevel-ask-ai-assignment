## Reproduce

```bash
npm run eval:scenarios -- --scenario-dir eval/scenarios,eval/brief-scenarios,eval/param-scenarios,eval/module-scenarios/coverage,eval/module-scenarios/wave1,eval/module-scenarios/m45-m47/development,eval/module-scenarios/m45-m47/reporting,eval/module-scenarios/m45-m47/trails,eval/module-scenarios/questions,eval/module-scenarios/role-ids,eval/policy-scenarios/partial-confirmation --repeat 1 --label port-ner-release-luna-final3
npm run report -- --label port-ner-release-luna-final3
```

The planner comes from `PLANNER` in `.env`; left unset, a Token Plan key selects qwen and no key selects claude-cli (see `server/src/planner/index.ts`). The scenarios are in `eval/scenarios/`, `eval/brief-scenarios/`, `eval/param-scenarios/`, `eval/module-scenarios/coverage/`, `eval/module-scenarios/wave1/`, `eval/module-scenarios/m45-m47/development/`, `eval/module-scenarios/m45-m47/reporting/`, `eval/module-scenarios/m45-m47/trails/`, `eval/module-scenarios/questions/`, `eval/module-scenarios/role-ids/`, `eval/policy-scenarios/partial-confirmation/`, the targets in `eval/targets.json`, and every recorded run in `eval/results/history.jsonl`.

Cost per successful task is everything spent, failed and infra runs and repair rounds included, divided by the runs that passed.

**Pricing and test conditions:** this planner runs `claude -p` on a Claude subscription. Cost is Claude Code's own estimate at Anthropic API list prices (`total_cost_usd`), not money spent. Each model call also starts a process, about 1.5 s of every call's latency, which an API client wouldn't pay. Prompt caching is Claude's automatic prefix cache: the system prompt is kept byte-identical between calls so it can be read from cache.

## Reproduce

From `server/`:

```bash
npm run eval:scenarios -- --repeat 3 --label planner-3x
npm run eval:scenarios -- --repeat 3 --label baseline-3x --agent baseline
npm run report -- --label planner-3x --compare baseline-3x
```

The planner comes from `PLANNER` in `.env` (see `server/src/planner/index.ts`). The scenarios are in `eval/scenarios/`, the targets in `eval/targets.json`, and every recorded run in `eval/results/history.jsonl`.

Cost per successful task is everything spent, failed and infra runs and repair rounds included, divided by the runs that passed.

**Pricing and test conditions:** this planner calls a Qwen Token Plan's OpenAI-compatible endpoint directly (strict `json_schema` output, or `json_object` with the schema in the prompt when `QWEN_RESPONSE_FORMAT=json_object`; thinking off unless `QWEN_THINKING` is set). Token Plan usage is prepaid, so cost cells marked (list rate) price the reported tokens at Alibaba Cloud Model Studio's pay-as-you-go rates for the same model (`LIST_RATES` in `server/src/eval/report.ts`: Singapore, busy hours; idle hours cost half). That is what the same traffic would cost without the plan, not money spent. Latency is a direct HTTPS call with no process startup.

## Reproduce

From `server/`:

```bash
npm run eval:scenarios -- --scenario-dir eval/scenarios,eval/brief-scenarios,eval/param-scenarios --repeat 1 --label deepseek-emptyloop-planner-1x-r2
npm run eval:scenarios -- --scenario-dir eval/scenarios,eval/brief-scenarios,eval/param-scenarios --repeat 1 --label deepseek-final-baseline-1x --agent baseline
npm run report -- --label deepseek-emptyloop-planner-1x-r2 --compare deepseek-final-baseline-1x
```

The planner comes from `PLANNER` in `.env` (see `server/src/planner/index.ts`). The scenarios are in `eval/scenarios/`, `eval/brief-scenarios/`, `eval/param-scenarios/`, the targets in `eval/targets.json`, and every recorded run in `eval/results/history.jsonl`.

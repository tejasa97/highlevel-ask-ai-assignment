Tokens and calls are the measured cost; dollars are derived from them. Cost per successful task is everything spent, failed and infra runs and repair rounds included, divided by the runs that passed.

**Pricing and test conditions:** this planner calls a Qwen Token Plan's OpenAI-compatible endpoint directly (strict `json_schema` output, or `json_object` with the schema in the prompt when `QWEN_RESPONSE_FORMAT=json_object`; thinking off unless `QWEN_THINKING` is set). Token Plan usage is prepaid, so cost cells marked (list rate) price the reported tokens at Alibaba Cloud Model Studio's pay-as-you-go rates for the same model (`LIST_RATES` in `server/src/eval/report.ts`: Singapore, busy hours; idle hours cost half). That is what the same traffic would cost without the plan, not money spent. Latency is a direct HTTPS call with no process startup.
